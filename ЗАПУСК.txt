ХРОНИКИ КРАКЕНА 888 — ЗАПУСК

1. Установите Node.js 22.5 или новее.
   Проверить:  node -v

2. Откройте терминал (в Windows — PowerShell) в этой папке и выполните:

   node server/server.mjs

   npm install делать НЕ нужно — внешних зависимостей нет.

3. Откройте в браузере:  http://localhost:8888

4. При первом запуске в консоли напечатается логин и пароль администратора:

      email:    admin@kraken888.local
      password: kraken888

   Войдите (Аккаунт -> Вход) и СРАЗУ смените пароль: Профиль -> Сменить пароль.

--------------------------------------------------------------------------

СВОЙ ПОРТ И ДОМЕН

   PORT=3000 node server/server.mjs

На боевом домене обязательно укажите адрес — он попадёт в canonical,
Open Graph и sitemap.xml:

   KC_ORIGIN=https://ваш-домен.ru node server/server.mjs

Windows PowerShell:

   $env:KC_ORIGIN="https://ваш-домен.ru"; node server/server.mjs
