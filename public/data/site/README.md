# Контент главной страницы «Хроники Кракена»

Эти JSON-файлы наполняют главную и связанные с ней разделы (`/about`,
`/about/history`, `/news`, `/achievements`, `/team`, `/hall-of-fame`,
`/tournament`). Отдельной админки для них пока нет (см. ТЗ, раздел 13) —
правьте файлы напрямую и перезапускайте сервер не нужно, они читаются на
каждый запрос браузера.

Все текстовые поля — объект `{ "ru": "...", "en": "..." }`, кроме дат,
URL и служебных полей. Пустая строка `""` или пустой массив `[]` для сайта
означает «материал ещё не готов» — страница сама покажет аккуратное
состояние ожидания вместо ошибки или выдуманного контента. **Не вставляйте
сюда ничего непроверенного** — заказчик явно попросил не придумывать
даты, имена, результаты и т.д.

## about.json

- `project.summary` — краткое описание проекта и его связи с сервером 888
  (несколько предложений, для главной и `/about`).
- `history.teaser` — краткая история в 1–2 абзацах, для главной и `/about`.
- `history.milestones[]` — полная хронология для `/about/history`:
  `{ id, date, title: {ru,en}, body: {ru,en}, image }`. `date` — строка,
  формат на ваше усмотрение (год или точная дата).

## news.json → `items[]`

`{ slug, title: {ru,en}, date, category, excerpt: {ru,en}, image, body: {ru,en}, published }`

- `slug` — часть адреса `/news/<slug>`, латиницей, без пробелов.
- `category` — например `project` / `server` / `tournament` (см. ТЗ §6).
- `published: false` — черновик, на сайте не показывается.
- На главной показываются 3 последних опубликованных по `date` (новые
  сверху).

## achievements.json → `items[]`

`{ id, title: {ru,en}, season, result: {ru,en}, description: {ru,en}, image, featured }`

- `featured: true` — попадает в подборку на главной. Порядок на главной —
  порядок в массиве.
- Если `items` пуст, блок на главной и в `/achievements` полностью
  скрывается (ТЗ §7).

## team.json

- `leader` — один объект или `null`: `{ nick, avatar, role: {ru,en}, area: {ru,en}, contact: { label: {ru,en}, url } }`.
- `officers[]` — массив офицеров того же формата.
- `contact` можно не указывать (`null`) — тогда кнопка связи не рисуется
  вовсе, а не ведёт в никуда (ТЗ §8).

## hall-of-fame.json → `items[]`

`{ nick, avatar, contribution: {ru,en}, period }`

- `period` — например `"2023–2024"`, произвольная строка.
- Раздел про **бывших** участников — не указывайте здесь действующих
  офицеров (см. team.json).

## tournament.json

- `status` — один из `coming-soon | announced | active | finished`.
  Пока `coming-soon` — на сайте показывается блок «Раздел готовится» без
  недействующей кнопки (ТЗ §10).
- `name`, `description` — заполняются при `status !== 'coming-soon'`.
- `ctaEnabled` + `ctaUrl` — включить кнопку перехода на саму турнирную
  страницу, когда перенос завершён.
