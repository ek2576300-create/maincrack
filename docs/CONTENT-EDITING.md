# Редактирование контента главной страницы

Разделы «О проекте», «История», «Новости», «Достижения», «Команда 888»,
«Легенды 888» и «Турнир» не имеют отдельной админ-панели — по ТЗ (раздел 13)
это допустимо, пока нет подходящей CMS: контент хранится в структурированных
JSON-файлах в `public/data/content/`. Правки в этих файлах подхватываются
сайтом без пересборки (кэш — 5 минут, как и у остальных `/data/*`).

**Правило для всех файлов: не заполняйте поля выдуманными данными.** Пустой
список или `null` рендерится как аккуратное пустое состояние («Раздел
готовится», «Новости появятся здесь» и т.д.) — это ожидаемое поведение до
получения реальных материалов, а не баг.

## `project.json`

```jsonc
{
  "description": { "ru": "…", "en": "…" },   // краткое описание проекта, блок «О проекте»
  "history": {
    "status": "pending" | "ready",           // "pending" → показывается note и пустой список
    "note": { "ru": "…", "en": "…" },        // почему истории пока нет / что уточняется
    "milestones": [
      {
        "date": "2024",                       // строка: год, дата или период
        "title": { "ru": "…", "en": "…" },
        "text":  { "ru": "…", "en": "…" },
        "image": "/static/img/…"              // необязательно
      }
    ]
  }
}
```

Когда придут материалы от Катаны — переключите `history.status` на `"ready"`
и заполните `milestones`. На главной показываются первые 3–5 вех, полная
хронология — на `/about/history`.

## `news.json`

```jsonc
{
  "posts": [
    {
      "slug": "pervaya-novost",              // латиница/цифры/дефисы, уникальный, часть URL /news/:slug
      "title": { "ru": "…", "en": "…" },
      "date": "2026-09-11",                  // ISO-дата публикации, используется для сортировки
      "category": "project" | "server" | "tournament",
      "excerpt": { "ru": "…", "en": "…" },   // краткий анонс для карточки
      "body": { "ru": "…", "en": "…" },      // полный текст (можно с переносами строк)
      "image": "/static/img/…",              // необязательно
      "draft": false                          // true — не показывать нигде, кроме прямой ссылки для проверки
    }
  ]
}
```

На главной — три последних `draft: false` поста по `date`. `/news` — полный
список. `/news/:slug` — открытая по `slug` запись.

## `achievements.json`

```jsonc
{
  "items": [
    {
      "slug": "sezon-5-pobeda",
      "title": { "ru": "…", "en": "…" },
      "when": "Сезон 5, 2025",               // сезон/дата — произвольная строка
      "result": { "ru": "1 место", "en": "1st place" },
      "text": { "ru": "…", "en": "…" },
      "image": "/static/img/…"
    }
  ],
  "featuredSlugs": ["sezon-5-pobeda"]         // какие показывать на главной и в каком порядке
}
```

## `team.json`

```jsonc
{
  "leader": {
    "nick": "…", "avatar": "/static/img/…",
    "role": { "ru": "Глава альянса", "en": "Alliance leader" },
    "area": { "ru": "…", "en": "…" },         // необязательно
    "contact": { "label": "Discord", "url": "https://discord.gg/…" } // необязательно — без него кнопка связи не рисуется
  },
  "officers": [
    { "nick": "…", "avatar": "…", "role": { "ru": "Офицер", "en": "Officer" }, "area": { … }, "contact": { … } }
  ]
}
```

`leader: null` → блок руководства показывает пустое состояние вместо
неполного/выдуманного состава.

## `hall-of-fame.json`

```jsonc
{
  "members": [
    {
      "slug": "…", "nick": "…", "avatar": "/static/img/…",
      "period": "2022–2024",                  // необязательно, если период неизвестен — не указывайте
      "text": { "ru": "…", "en": "…" }         // вклад в развитие сообщества
    }
  ],
  "featuredSlugs": ["…"]
}
```

Сюда попадают только **бывшие** участники — не присваивайте им текущие
должности (для действующего руководства — `team.json`).

## `tournament.json`

```jsonc
{
  "status": "preparing" | "ready",
  "name": { "ru": "…", "en": "…" },
  "description": { "ru": "…", "en": "…" },
  "cover": "/static/img/…"                    // необязательно
}
```

Пока `status: "preparing"` — на сайте только статус «Раздел готовится», без
кнопки перехода. Полноценная страница турнира (сетки, участники, результаты)
подключается отдельно, когда перенос данных с прежнего ресурса завершён —
см. `docs/TOURNAMENT-MIGRATION.md`.
